# Renewal Radar — Frontend

React (Vite) frontend for Renewal Radar. See the [project README](../README.md)
for what this app does, architecture, and setup instructions.

Quick start (from this directory):

```
npm install
npm run dev
```

Requires the FastAPI backend running at `http://localhost:8000` (or set
`VITE_API_BASE_URL` to point elsewhere).
